# PM2 Production Deployment Guide

DeployHub can be hosted reliably 24/7 using PM2 process manager on Linux (Ubuntu/Debian) or Windows servers.

---

## 1. Prerequisites

- **Node.js**: >= 18 LTS (`node -v`)
- **PM2**: Install globally
  ```bash
  npm install -g pm2
  ```
- **MongoDB**: Ensure MongoDB service is running (`mongod`).
- **Redis** *(Optional)*: If Redis is not available, DeployHub automatically falls back to its built-in in-memory queue.

---

## 2. Configure Environment (`.env`)

Ensure your `.env` file exists in the root folder:
```bash
# Production environment
NODE_ENV=production
PORT=5000

# Domain
PLATFORM_DOMAIN=pateldeeep.me
API_URL=http://localhost:5000

# Secrets (use strong random 32+ char keys in production)
JWT_SECRET=super-secret-deployhub-jwt-token-key-change-in-production-32chars
JWT_REFRESH_SECRET=super-secret-deployhub-refresh-token-key-32chars

# Databases
MONGODB_URI=mongodb://localhost:27017/deployhub
REDIS_URL=redis://localhost:6379
```

---

## 3. Build Frontend & Backend

Compile the Vite React frontend into `dist/` and the TypeScript backend into `server/dist/`:
```bash
npm run build
```

---

## 4. Start the Application with PM2

Launch DeployHub using the provided `ecosystem.config.cjs`:
```bash
pm2 start ecosystem.config.cjs
```

Or using `npx` if PM2 is not installed globally:
```bash
npx pm2 start ecosystem.config.cjs
```

---

## 5. Helpful PM2 Commands

| Action | Command |
|---|---|
| Check status | `pm2 status` |
| View live logs | `pm2 logs deployhub-server` |
| View system monitors | `pm2 monit` |
| Restart app | `pm2 restart deployhub-server` |
| Stop app | `pm2 stop deployhub-server` |
| Reload with zero-downtime | `pm2 reload deployhub-server` |

---

## 6. Auto-Restart on Server Reboot

### On Linux (Ubuntu / Debian VPS):
```bash
pm2 save
pm2 startup
# Copy & paste the command generated by pm2 startup into terminal
```

### On Windows Server:
```powershell
npm install -g pm2-windows-service
pm2-service-install
pm2 save
```
